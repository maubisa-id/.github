# Panduan Kontribusi

Terima kasih atas minat Anda berkontribusi ke proyek Maubisa. Panduan ini berlaku sebagai default
untuk repositori organisasi (`maubisa-id`) yang belum punya `CONTRIBUTING.md` sendiri.

## Alur singkat

1. **Cari dulu.** Lihat issue yang sudah ada sebelum membuka yang baru.
2. **Diskusikan perubahan besar.** Untuk fitur besar, buka issue lebih dulu supaya arahnya sepakat
   sebelum menulis kode.
3. **Fork dan buat branch.** Kerjakan di branch terpisah dengan nama yang jelas.
4. **Buat perubahan kecil dan fokus.** Satu pull request untuk satu tujuan. Sertakan langkah uji
   bila relevan.
5. **Ikuti standar repo.** Jalankan linter dan test yang sudah ada sebelum membuka pull request.

## Standar per repositori

Tiap repositori bisa punya panduan lebih rinci. Contoh lengkap ada di
[account-center-starter/CONTRIBUTING.md](https://github.com/maubisa-id/account-center-starter/blob/main/CONTRIBUTING.md).
